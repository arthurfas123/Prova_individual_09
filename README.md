# Calculadora de IMC

Projeto simples em Python para calcular o Indice de Massa Corporal (IMC)
a partir do peso e da altura informados pelo usuario.

## Formula

IMC = peso / (altura * altura)

## Classificacao

| IMC | Classificacao |
|-----|----------------|
| < 18.5 | Abaixo do peso |
| 18.5 a 24.9 | Peso normal |
| 25.0 a 29.9 | Sobrepesso |
| 30.0 a 34.9 | Obesidade grau I |
| 35.0 a 39.9 | Obesidade grau II |
| >= 40.0 | Obesidade grau III |

## Como executar

```
python imc.py
```
